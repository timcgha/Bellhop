Module split (refactor/modules → merged to main)
------------------------------------------------
Split the monolithic index.html game script into src/ modules plus level
data, following Bellhop_claude.md sequencing. Pure move — no gameplay or
physics changes.

Structure:
  src/util.js       clamp, lerp, damp, moveTo, rand, TAU, angDamp, smooth;
                    isTouch bootstrap; started flag
  src/audio.js      WebAudio, SFX, music scheduler
  src/input.js      keyboard, touch, gamepad → IN struct
  src/render.js     renderer, scene, camera, lights, shared materials/geometries
  src/fx.js         particle pool, rings, floating Z sprites
  src/entities.js   world arrays, ground, entity builders, loadLevel(),
                    updateChecks, triggerWin, updateWin
  src/player.js     buildPlayer, P struct, movement, abilities; window.__P
  src/enemies.js    world updates (gloops, goo, items, snoozles, etc.)
  src/hud.js        HUD, toasts, start screen wiring
  src/game.js       camera, main loop, buildLevel() call, window.__W
  levels/level1.js  LEVEL1 placement data (hedges, path, spawns, steps)
  build.js          concatenates levels/*.js + src/*.js into index.html
  tools/load-game.js  test helper: load built marker content or concat src/

Build markers in index.html:
  // ---- BUILD:START ----
  // ---- BUILD:END ----

Harness changes:
- Removed string-replacement hooks for P, CAM, and W.
- Game exports window.__P, window.__CAM, and window.__W directly from source.
- load-game.js uses built index.html content when markers are populated;
  otherwise concatenates levels/ + src/ for development.

index.html size after build.js: 86,201 bytes (was 85,409 before split;
+792 bytes from build comment headers).

Verified: with src/ and levels/ temporarily renamed, tests still pass using
the built marker content in index.html.
